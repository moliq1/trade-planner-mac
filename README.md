# 交易计划助手（Trade Planner for Mac）

一个完全离线的 **macOS 13+ 原生菜单栏应用**，用于股票做多交易的计划计算与保存。源代码基于 SwiftUI + JSON 原子写入，计算核心使用 Swift Decimal。

## 功能

- 止损、止盈价格与百分比**同时可见且双向同步**，无须切换标签；修改计划买入价后自动按最近编辑的价格或百分比重新计算
- 止损和止盈百分比支持手动输入或快捷滑块，手动输入不受滑块上限限制
- 预期收益/风险比 R 与理论盈亏平衡胜率
- **计划买入股数（选填）**：主界面直接显示**本笔买入金额（人民币）、仓位占本金比例、止损亏损（人民币）、本笔本金风险占比**，不用展开折叠区；仍显示盈亏比与目标盈利
- 总本金**默认 1,500,000**（可修改），风险预算**默认 1%**（可修改）；自动计算参考股数，明确区分**手动计划股数**和**按风险预算参考股数**，若本笔风险超预算则警告
- 通过每手股数调整不同市场交易单位；手动股数非整数手仅提醒、不自动改变用户输入
- 主界面聚焦 A 股和港股；A 股价格按人民币、港股价格按港币输入，**所有资金金额、收益、损失和风险比例统一按人民币计算**
- 港股可编辑「1 HKD = ? CNY」，默认固定为 **0.85633**（2026-11-12 中国外汇交易中心人民币汇率中间价：100 HKD = 85.633 CNY），不自动联网更新，不代表港股通券商实际结算价格；保存计划时同时保存汇率
- JSON 原子写入 本地保存、搜索、编辑、删除历史交易计划，CSV 导出
- 菜单栏快捷弹窗、历史管理窗口，适配系统深色/浅色外观；菜单栏窗口右上角有 **「退出」按钮**（也支持窗口聚焦时 ⌘Q）
- 无需行情 API、证券账号、服务器或网络连接

## 最方便的安装方式（不需要在 Mac 安装 Xcode）

最低系统要求：**macOS 13 Ventura**（包括 macOS 13.5，Intel 和 Apple Silicon 双架构）。

1. 打开 [Actions 页面](https://github.com/moliq1/trade-planner-mac/actions)。
2. 选择 **macOS build and core tests**，进入最新一条显示绿色勾号的构建；需要时也可以点 **Run workflow** 手动构建。
3. 到运行详情页底部的 **Artifacts** 区域下载 `TradePlanner-macOS`。
4. 解压下载的 ZIP 后，里面会有第二个 `TradePlanner-macOS-unsigned.zip`；再次解压得到 `TradePlanner.app`。
5. 将 `TradePlanner.app` 拖到「应用程序」目录并打开；它默认只显示在**屏幕顶部菜单栏**，不会显示在 Dock。点击走势图图标就能计算、保存和访问历史计划。

**提示：** 这是在你自己的 GitHub Actions macOS runner 上编译的**非正式签名/未公证**测试包，并非经过 Apple 审核的正式发行版。macOS 可能阻止首次打开：如果你已确认 ZIP 来自自己仓库的成功构建并愿意承担风险，尝试打开应用后，到「系统设置 → 隐私与安全性 → 仍要打开（Open Anyway）」为它授权。**不要关闭系统级 Gatekeeper 或安装来源安全检查。** 如果 macOS 报告应用已损坏或发现恶意软件，不要强行绕过。

Actions 测试包默认只保留 30 天；这是测试渠道，不是正式发行渠道。如果状态是红色失败，说明还没编译成功，需要看构建日志，不要假设可以运行。

Xcode 15+，打开 `TradePlanner.xcodeproj`，选择 `TradePlanner` Scheme 和 `My Mac`，按 `⌘R` 启动。仅为运行已编译好的 App **不需要本地 Xcode**。安装 Apple Command Line Tools 并不等于安装完整 Xcode：`xcodebuild` 必须通过完整 Xcode 提供。

GitHub Actions 自动运行计算测试、验证 arm64 / x86_64 两种架构与 macOS 13.0 最低版本、`xcodebuild` Release 编译、使用 ad-hoc 临时签名并上传压缩 App。

## 计算口径

本版仅支持股票**做多**且要求 `0 < 止损价 < 买入价 < 止盈价`。

| 指标 | 公式 |
|---|---|
| 亏损比例 | `(买入价 - 止损价) / 买入价 × 100%` |
| 盈利比例 | `(止盈价 - 买入价) / 买入价 × 100%` |
| 盈亏比 R | `(止盈价 - 买入价) / (买入价 - 止损价)` |
| 理论盈亏平衡胜率 | `1 / (1 + R)`，未计费用 |
| 资金风险预算 | `账户资金 × 单笔最大风险比例` |
| 参考股数 | `min(资金风险预算/每股风险, 账户资金/买入价)`，再向下取整到可交易的每手数量 |

**注意：** 总本金默认 1,500,000 **人民币**。港股参考价输入 HKD，人民币买入金额 = 港币买入价 × 股数 × 港币兑人民币参考汇率；止损亏损（人民币）= (买入价 − 止损价) × 股数 × 参考汇率；止盈盈利（人民币）= (止盈价 − 买入价) × 股数 × 参考汇率；本笔本金风险比例 = 止损亏损人民币金额 / 人民币总本金 × 100%。A 股参考汇率固定为 1。未填手动股数只展示按预算参考仓位，**不会**把建议股数误记为实际计划。计算未考虑实际结算时的汇率变化或港股通换汇差价，也不含手续费、印花税、税费、滑点、跳空；并不保证止损一定成交。A 股默认每手 100 股，港股不同标的每手数量不同，请手动调整。未输入仓位预算时，请同时清空资金和最大风险比例。历史记录保存在本机，删除应用数据前建议导出 CSV；CSV 暂不支持导回，修改历史计划会覆盖当前版本，不提供修改日志。本地数据文件位于 `~/Library/Application Support/TradePlanner/trade-plans.json`，另有上次保存前的 `.backup` 文件备份；数据损坏时不会自动以空数据覆盖。

## 代码结构

- `TradePlanner/App/TradePlannerApp.swift` — 菜单栏应用生命周期
- `TradePlanner/Core/TradeCalculator.swift` — 可独立测试的 Decimal 计算引擎
- `TradePlanner/Models/TradePlan.swift` — JSON 原子写入 数据模型和草稿
- `TradePlanner/Views/CalculatorView.swift` — 计算器和保存界面
- `TradePlanner/Views/HistoryView.swift` — 搜索、编辑、删除、CSV 导出
- `Tests/TradeCoreTests/` — 计算逻辑单元测试
- `.github/workflows/ci.yml` — GitHub Actions 构建、打包、上传测试版 App

## 系统兼容性

本项目已从 SwiftData（macOS 14+）改为 macOS 13 可用的 Codable + JSON 本地存储，并移除了 macOS 14 专属的 `ContentUnavailableView` 和双参数 `onChange`。GitHub CI 可验证二进制部署目标为 13.0，但**尚未在一台真实的 macOS 13.5 设备上完成 GUI 运行验证**。

## 交互与历史兼容性

- 价格与百分比两种输入均始终显示，**最后操作的字段**是计算来源：例如最后输入止损价，再修改买入价，会保留止损价、重算亏损比例；若最后输入亏损比例，则保留比例、重算止损价。百分比滑块只负责快速输入，不影响手动输入更大/更小的合法比例。
- 新增手动股数、实际盈亏金额和本金风险字段都是可选字段，旧版 JSON 历史计划仍可解码、浏览及编辑，避免覆盖原有记录。
- 对历史记录的“预算参考股数”和“计划买入股数”分别展示，并分别导出 CSV。

## 退出应用

本工具为菜单栏常驻应用，不会在 Dock 中显示。点击顶部菜单栏的走势图图标，在弹出的计算器**右上角点击「退出」**即可结束进程；也可尝试在窗口处于焦点时按 `⌘Q`。仅关闭弹窗或按 Esc 不等于退出，应用会继续常驻菜单栏。已经点击「保存交易计划」的内容保存在本机。

## 2026-11-12 人民币统一核算更新

- 选择 A 股时：价格、资金与损益均按 CNY。
- 选择港股时：股票报价保留 HKD，汇率可以自行调整；所有**金额**与资产风险、参考仓位统一按 CNY 计算。示例：100 HKD × 100 股 × 0.85633 = 8,563.30 CNY，止损 95 HKD 对应亏损 428.165 CNY（展示时四舍五入）。
- 历史 JSON 记录向后兼容：已有港股记录没有汇率字段则显示 **HKD（旧版）**，避免将过去未转换的金额误标为 CNY。编辑并保存后才使用新版汇率重算。
- 固定参考： [新华社 2026-11-12 人民币中间价](https://www1.xinhuanet.com/20261112/97116e6012634afcaefaa35c8e5f9a92/c.html)；本工具离线运行，不会自动更新汇率。


## A/H 红涨绿跌与盈亏展示

- A/H 市场习惯：**盈利红色、亏损绿色**。止盈/止损区域的文字、滑块、金额、盈亏比视觉条以及历史记录统一遵守该配色；超预算警告使用橙色。
- 在「止损」滑块下方显示本笔预计止损亏损（绿色，人民币）；「止盈」滑块下方显示本笔预计止盈盈利（红色，人民币）。未填写计划买入股数时显示提示，不冒充真实仓位。
- 主界面排序：买入 → 止损与亏损金额 → 止盈与盈利金额 → **盈亏比** → **仓位和风险** → 保存与交易理由。港股金额仍使用已设置汇率转换为 CNY。

## 历史窗口与数字显示优化

- 从菜单栏点击「历史」：先隐藏菜单栏下拉窗口，再激活应用，将唯一的历史窗口置前；历史窗口已经打开时复用，不重复创建。使用 AppKit 官方窗口操作与 SwiftUI Window 场景。
- 历史详情不再展示「预算参考股数 / 预算理论亏损 / 预算理论盈利」，CSV 中也移除这三个参考字段。此前这些是用总本金、单笔风险预算、止损距离和整手限制推算的**参考仓位**，不是实际买入计划。
- 历史记录中的实际买入金额、止损亏损、止盈盈利以**两位小数**显示和导出（例如 14,447.9998 显示为 14,448.00）。原始 JSON 仍保留 Decimal 的完整精度，不改变用户保存的交易数据。买入价、止损价、止盈价最多显示四位小数，避免损失股票报价精度。


## 按状态分组及已结束交易的实际盈亏（2026-11-16）

- 历史窗口左侧按 **计划中 / 已买入 / 已结束 / 已取消** 分组；每条记录显示公司名称、买入价、止损价、止盈价（报价币种），**不显示盈亏比 R**；仍可通过搜索框按公司、代码或备注搜索。
- 编辑已买入计划时，状态切换到 **已结束** 后，自动出现 **实际卖出价** 输入框。必须填写该笔的买入股数与正数卖出价才能保存；如果原计划未填写股数，先补全。自动保存结束时间及一次性全数卖出的计算快照。
- 已结束计划新增 **卖出金额（人民币）、实际盈亏（人民币）、实际收益率、实际 R 倍数**；正收益红色、负收益绿色。示例：买入 100、止损 95、卖出 110、2000 股，则实际收益 +20,000 元、+10%、+2 R（费用与汇率变化前）。
- **公式**：实际盈亏 RMB =（卖出价 − 买入价）× 买入股数 × 汇率；实际收益率 =（卖出价 − 买入价）÷ 买入价；实际 R =（卖出价 − 买入价）÷（买入价 − 止损价）。A 股汇率为 1，港股延续交易计划中保存的 HKD/CNY 汇率；不同于实际港股通成交的买入/卖出结算汇率。暂不支持部分卖出、分批成交与手续费扣减；结果属于按输入参数估算的**交易前费用毛盈亏**。
- 从已结束改回未结束会清空实际卖出与实现盈亏字段；保存仍会覆盖当前计划快照。本版新增数据字段均为可选，旧 JSON 历史不丢失；旧版「已结束」但未记录卖出价的记录会提示补录，不会虚构收益。
- CSV 导出追加实际卖出、实际盈亏和结束时间字段，保持原有本地路径与数据备份。

## 2026-11-19 更新：买入日期、交易复盘、菜单栏右键

- 新建计划自动填写新建当天的**买入日期**，精确到日；可手动修改。交易日期由用户填写，不自动同步券商实际成交。
- 历史记录保留按状态分组，**组内按买入日期倒序**；搜索和 CSV 也按买入日期排序。左栏标注买入日期。
- 旧版历史记录未保存买入日期，暂以创建日期作为排序依据，同时明确标注「买入日期待核实」，可编辑补录；兼容原有 JSON 数据。
- 已结束计划新增单独的**交易复盘**文字框，可以记录计划执行、情绪、失误和改进；与最初买入依据分开保存，并导出 CSV。
- 将 SwiftUI MenuBarExtra 换为 AppKit 原生 NSStatusItem + NSPopover，**左键显示/关闭计算器**、**右键打开历史记录/退出应用菜单**；支持 macOS 13.5。
